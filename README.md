# 股海练兵 · 股票模拟交易与复盘

用**真实 A 股历史行情**练习选股，每周自动生成复盘报告，并用王者段位体系量化你的投资纪律。

零依赖、零构建 —— 双击 `app/index.html` 就能跑。

---

## 核心特性

### 一、真实行情回放，不是随机数字

- 数据集包含 **38 只 A 股 + 沪深300 基准**，覆盖 **646 个交易日**（2024-01-02 ~ 2026-09-01）
- 日线 OHLC 100% 来自真实历史行情，前复权
- 日内走势由确定性算法生成，严格锚定真实的**开 / 高 / 低 / 收**四点，全程不越界
- 全部随机性来自 FNV-1a + mulberry32 确定性 PRNG（种子 = 股票代码 + 交易日），**同一标的同一天的走势，任何时候重放都完全一致**

标的池横跨 19 个行业，β 从 0.02（长江电力）到 1.63（东方财富），年化波动从 15.85% 到 60.77%（兆易创新）—— 这是为了让"分散化""β 管理""仓位控制"这些概念能被真实数据验证，而不是空谈。

### 二、完整的 A 股交易规则

| 规则 | 实现 |
|---|---|
| T+1 | 当日买入不可卖出，下一交易日自动解锁 |
| 整手交易 | 买入须为 100 股整数倍；零股仅可一次性卖出 |
| 涨跌停 | 主板 ±10%，创业板（300/301）与科创板（688）±20% |
| 停牌 / 未上市 | 交易屏蔽 |
| 费用 | 佣金 0.025%（双向，最低 5 元）+ 印花税 0.05%（卖出单边）+ 过户费 0.001%（双向） |
| 成本法 | 移动加权平均，买入成本含买入费用 |

初始本金 100,000 元。持仓市值与账户盈亏实时更新。

> 顺带一个真实约束：10 万本金**买不起 1 手茅台**（约 15.5 万元）。这不是 bug，而是 A 股整手交易的现实——资金规模决定了你的可选标的范围。买入面板会实时显示"1 手需 XX 元"。

### 三、每周自动生成复盘报告

每 5 个交易日自动结算。报告包含四层：

**1. 收益归因（Brinson 式，可加总对账）**

```
本周收益 = 市场β + 选股α + 交易择时 + 残差

市场β   = 期初股票仓位 × 基准涨跌
选股α   = Σ 期初权重ᵢ × (个股涨跌ᵢ − 基准涨跌)
交易    = 买入贡献 − 卖出贡献 − 交易费用
残差    = 实际收益 − 上述三项之和
```

四项严格加总等于实际周收益率（测试误差 < 0.5 个百分点）。这意味着你能清楚看到：**这周赚的钱，到底是大盘给的、选股选对的、还是买卖时点踩准的。**

**2. 本周操作明细与持仓变动**

**3. 行为诊断（14 条可量化规则）**

每条规则都基于你那一周的真实操作数据给出数字证据：

| ID | 规则 | ID | 规则 |
|---|---|---|---|
| R01 | 追高买入 | R08 | 极端仓位（现金过高 / 接近满仓） |
| R02 | 恐慌杀跌 | R09 | 向亏损仓位加仓（向下摊平） |
| R03 | 过度交易 | R10 | 同一标的周内反复进出 |
| R04 | 持仓周期过短 | R11 | 交易费用显著侵蚀收益 |
| R05 | 处置效应（截断利润、让亏损奔跑） | R12 | 行业暴露过度集中 |
| R06 | 缺乏止损纪律 | R13 | 空仓错过市场上涨 |
| R07 | 单一标的仓位过重 | R14 | 过早兑现盈利 |

**4. 经验教训 + 下周行动建议（P0/P1/P2 优先级）**

### 四、王者段位体系

青铜 → 白银 → 黄金 → 铂金 → 钻石 → 星耀 → 王者，7 大段位，随表现动态升降。

胜负判定与加减星：

| 条件 | 星数 |
|---|---|
| 跑赢沪深300 | **胜利 +1 星** |
| 跑输沪深300 | **失败 −1 星** |
| 胜利且表现分 ≥ 70（MVP） | 额外 **+1 星** |
| 连胜 ≥ 3 次 | 额外 **+1 星** |
| 青铜Ⅲ 0 星时失败 | **不掉星**（新手保护） |
| 失败且勇者积分 ≥ 60 | **消耗 60 分保星** |

**段位不是只看收益。** 综合表现分四维加权：

```
表现分 = 0.35 × 收益 + 0.25 × 风险 + 0.30 × 纪律 + 0.10 × 学习
                        └─ 回撤/集中度   └─ 违规扣分
```

收益只占 35%，风险与纪律合计 55%。**靠运气重仓押中一只票上不了分** —— 这是刻意设计，目的是逼你补仓位管理和止损纪律，而不是鼓励冒险。

### 五、教学体系

16 门课程，分入门 / 进阶 / 高阶三层，覆盖股票本质、K 线与 A 股规则、交易成本、仓位管理、止损止盈、分散化与 β、PE/PB/股息率、三张财务报表、处置效应、追涨杀跌、过度交易、均线滞后性、资产配置、周期股择时、夏普比率、复盘方法论。

每门课含核心要点 + 落地检查清单 + 自测题（带解析）。**推荐引擎会读取你当周的诊断结果**，优先推送命中你问题的课程——比如诊断出"处置效应"，就会推 c09。

## 快速开始

### 方式一：本地服务器（推荐）

```bash
python tools/serve.py              # 默认 http://127.0.0.1:8321/
python tools/serve.py --port 9000  # 换端口
python tools/serve.py --open       # 自动打开浏览器
```

> ⚠️ **别用 `python -m http.server`。** 标准库是单线程的，一次只处理一个请求；浏览器会并发拉取 12 个 JS 文件，单线程下请求被排队甚至超时，表现为随机几个脚本加载失败、页面卡在"正在加载真实行情数据…"。`serve.py` 用 `ThreadingHTTPServer` 已解决。

### 手机 / 平板访问（同一 Wi-Fi）

```bash
# 1) 以局域网模式启动服务
python tools/serve.py --lan

# 2) 另开一个终端，生成扫码页（会自动探测局域网 IP）
pip install segno
python tools/lan_qr.py --open
```

`--lan` 等价于 `--host 0.0.0.0`，启动横幅会直接打印形如 `http://192.168.1.23:8321/` 的手机地址；`lan_qr.py` 则生成一份自包含的 `lan-access.html`（二维码内联为 SVG，不联网也能用），用微信「扫一扫」即可打开。

**打不开的排查顺序：**

1. **电脑上的服务窗口是否还开着** —— 关掉窗口服务就停了。
2. **手机是否连着同一个 Wi-Fi** —— 用了移动数据或另一个 Wi-Fi 都不行。
3. **AP 隔离** —— 部分公司/校园网禁止设备互访。改用手机热点让电脑连上来，再重跑一次 `lan_qr.py`。
4. **Windows 防火墙** —— 以管理员身份执行（端口号按实际替换）：

   ```cmd
   netsh advfirewall firewall add rule name="股海练兵-8321" dir=in action=allow protocol=TCP localport=8321 remoteip=localsubnet
   ```

   规则中的 `remoteip=localsubnet` 限定只允许局域网设备访问，不会把端口暴露到公网。

> 换 Wi-Fi 或重启路由器后局域网 IP 会变，重新运行 `python tools/lan_qr.py` 刷新扫码页即可。

### 方式二：直接双击 `app/index.html`

无需服务器、无需构建、无需联网。所有资源通过 `<script src>` 同步加载，不含任何 `fetch`/`XHR`，因此不受 `file://` 的 CORS 限制。

> 个别浏览器（如部分 Safari 版本）会限制 `file://` 下的 `localStorage`，若"刷新后进度丢失"请改用方式一。

### 方式三：静态托管

把 `app/` 整个目录上传至 GitHub Pages / Vercel / 腾讯云 EdgeOne Pages / Nginx 即可，无任何构建步骤。`app/data/market-data.js` 为 1.3 MB，建议开启 gzip（压缩后约 200 KB 量级）。

### 更新行情数据

```bash
python tools/fetch_market_data.py   # 从东方财富重新抓取，覆盖 data/ 与 app/data/
```

**技术栈**：原生 JavaScript（ES5 IIFE 模块）+ 手写 SVG 图表 + localStorage。无框架、无构建、无运行时依赖。

```
├─────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────┤
│  主控层  game.js      时钟推进 · 周结算 · 事件总线        │
├──────────┬──────────┬──────────────┬────────────────────┤
│ market   │ account  │ report       │ rank               │
│ 行情回放 │ 撮合/费用 │ 归因/诊断    │ 段位升降           │
```

```bash
node tools/smoke_test.js      # 引擎测试，40 项（无依赖）
```

**123 项断言全部通过。** 关键验证点：

- 日内路径起点严格等于真实开盘价、终点严格等于真实收盘价、全程不越界于真实最高/最低价

## 数据来源与限制

- **来源**：东方财富公开历史 K 线接口（`push2his.eastmoney.com`），日线、前复权
- **风险特征**（β / 年化波动 / 夏普 / 最大回撤）全部由真实行情回归计算，无估算

**已知限制**：

1. **数据源为第三方公开接口，非官方授权**。个人学习训练无碍；若商业发行需替换为持牌行情服务商。
2. **日内走势为算法生成，非真实分时数据**。它严格锚定真实的开/高/低/收四点且可复现，但**不等于**历史上真实发生的分时走势。
3. **费率**为当前市场主流区间的代表值，非任何特定券商报价。
4. **未建模**：集合竞价、大宗交易、现金分红到账（已用前复权处理价格）、新股申购。
5. **回放区间固定**为 2024-01-02 ~ 2026-09-01；走完 646 日后需重新开局或更新数据。
